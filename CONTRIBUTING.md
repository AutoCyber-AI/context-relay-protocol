# Contributing to CRP / crprotocol

Thank you for your interest in the Context Relay Protocol (CRP).

## Important: contributions are by approval only

CRP is an open specification and an open-core SDK, but the canonical
implementation and protocol direction are stewarded by AutoCyber AI.
**We do not accept unsolicited pull requests, issues, or code commits.**

If you would like to contribute:

1. Contact the maintainers first — see the project website or LinkedIn page.
2. Describe what you want to change and why.
3. Wait for explicit written approval before opening a pull request.
4. Approved contributors must sign a Contributor License Agreement (CLA).

Pull requests opened without prior approval will be closed.

## Security reports

If you discover a security issue, do **not** open a public issue. Contact
the maintainers privately with details and a reproduction path.

## Specification feedback

For protocol-level discussion, refer to the public specification documents
and contact the maintainers through the official channels listed on
[crprotocol.io](https://crprotocol.io).
