# Contributing to CRP

Thank you for your interest in the Context Relay Protocol (CRP).

This repository is currently **maintained by the core team** and is not accepting unsolicited pull requests or code changes from external contributors.

If you would like to contribute, please:

1. Open a discussion or issue describing your proposal.
2. Wait for a core maintainer to respond.
3. Only proceed with a pull request after explicit written approval.

This policy protects the protocol's governance, security, and release quality.

## Security

If you discover a security issue, please contact the maintainers privately. Do not open a public issue.
