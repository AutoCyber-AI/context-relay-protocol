# CRP Gateway — Deployment Guide

> This document previously contained detailed Railway deployment variables and
> service wiring for the managed CRP Gateway stack.
>
> That level of configuration has been **withheld from public publication**
> because it describes internal hosting architecture, third-party integrations,
> and secrets management that are not appropriate for a public repository.

## Public information

- **CRP Gateway** is available as a managed cloud service at
  `https://gateway.crprotocol.io`.
- **Self-hosting and white-label deployments** are available for Enterprise
  customers.
- For the public quick-start guide, see
  [`site-docs/getting-started/quickstart.md`](../site-docs/getting-started/quickstart.md).
- For the public self-hosting overview, see
  [`site-docs/guides/gateway-railway.md`](../site-docs/guides/gateway-railway.md).

## Obtaining the detailed deployment checklist

Enterprise and white-label customers receive the full deployment runbook
(including environment variables, Railway/PostgreSQL/Redis wiring, auth
integration, and domain setup) under NDA as part of onboarding.

To request access, contact **info@crprotocol.io** or your AutoCyber AI account
manager.
