## How to read these pages

- **SDK proxy pages** document the public namespace returned by `client.<namespace>`. They are thin, typed facades over the internal subsystem.
- **Internal module pages** document the underlying classes and functions that power the SDK. Import them directly when building on top of CRP rather than using the high-level client.
- **Options** on every `:::` block hide source code (`show_source: false`) and private members (`filters: ["!^_"]`).
